## About the Project

The College Library Management System is a web-based application designed to manage library activities efficiently. It provides separate interfaces for students and staff, making it easier to manage books, track issued books, and monitor borrowing activities.

## Features

### Student Features
- Student registration and login
- Student dashboard
- View available books
- Search books by title or other details
- Filter books by category
- View book details and availability
- View currently issued books
- View borrowing history
- Check due dates
- Manage profile details
- Forgot password option

### Staff Features
- Staff login
- Staff dashboard
- Add new books with book details and categories
- Edit book information
- Remove books that are not currently issued
- Issue books to students
- Process returned books
- View issue and return history
- Manage student information
- View reports
- Manage profile details

## Technologies Used

- HTML5 – Structures the website content.
- CSS3 – Styles the website and provides a responsive layout.
- JavaScript – Handles website interactions and functionality.
- Local Storage – Stores demo data in the browser.
- GitHub – Hosts and manages the project repository.
- GitHub Pages – Publishes the website online.

## How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Register an account or use the demo login credentials provided in the project, if available.

## How to Deploy on GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings**.
4. Select **Pages** from the sidebar.
5. Under the build and deployment section, select **Deploy from a branch**.
6. Choose the `main` branch and the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to publish the website.
9. Copy the published website link into the Live Demo section above.

Make sure `index.html` is located in the selected publishing folder.

## Project Objectives

- To simplify library book management.
- To provide separate access for students and staff.
- To make searching and tracking books easier.
- To maintain book issue and return records.

## Important Notes

- This project uses HTML, CSS, and JavaScript on the front end.
- Data stored in Local Storage is generally limited to the browser and device where it was saved.
- The demo does not provide a shared database between different users or devices.
- Password recovery is simulated unless a backend service and email integration are implemented.
- This version is intended for demonstration and academic purposes. A production system requires secure authentication, a backend, and a database.

## Future Enhancements
